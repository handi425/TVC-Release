Dokumentasi Lengkap EntryAjaib EA v30.77

EntryAjaib adalah Expert Advisor untuk MetaTrader 5 yang berfungsi sebagai panel eksekusi, perencanaan entry, pengelolaan SL/TP, manajemen basket posisi, trailing stop, dan monitoring risiko margin. EA ini bukan robot sinyal otomatis; keputusan entry tetap berada pada trader.

Catatan penting: dokumentasi ini mengikuti isi file EntryAjaib.mq5 versi 30.77. Beberapa fungsi ada di kode namun belum terhubung ke tombol UI; statusnya dijelaskan pada bagian "Fitur Internal".

0. Cara Implementasi EA

Bagian ini menjelaskan langkah demi langkah cara mengimplementasikan EntryAjaib EA dari nol hingga siap digunakan untuk trading di MetaTrader 5. Ikuti urutan langkah berikut agar EA berjalan dengan benar.

A. Persiapan File dan Lokasi

Buka Data Folder MetaTrader 5 Di terminal MT5, klik menu File → Open Data Folder. Folder ini adalah direktori data terminal tempat seluruh file MQL5 disimpan.
Masuk ke folder Experts Navigasi ke MQL5\Experts. Folder ini adalah lokasi khusus untuk file Expert Advisor (.mq5 dan .ex5).
Salin file EntryAjaib Copy file EntryAjaib.mq5 (dan EntryAjaib.ex5 jika sudah dikompilasi) ke dalam folder MQL5\Experts. Anda juga boleh membuat subfolder, misalnya MQL5\Experts\Entry_Ajaib\EntryAjaib.mq5.
Refresh Navigator Kembali ke terminal MT5, klik kanan pada bagian Expert Advisors di panel Navigator, lalu pilih Refresh. Jika tidak muncul, restart terminal MT5.

B. Setting Akun dan Permission

Login ke akun trading Gunakan akun demo untuk pengujian pertama kali. Pastikan koneksi ke server broker stabil.
Aktifkan Algo Trading Di toolbar atas MT5, pastikan tombol Algo Trading aktif (berwarna hijau). Jika tidak aktif, EA tidak akan bisa mengirim order.
Izinkan EA trading otomatis Saat memasang EA, centang opsi Allow Algo Trading di jendela input EA. Tanpa centang ini, EA hanya tampil di chart tetapi tidak bisa eksekusi order.
Cek permission symbol Pastikan symbol yang dipakai (misalnya XAUUSD, EURUSD) mengizinkan trading otomatis dan tidak diblokir oleh broker. Beberapa akun hanya memperbolehkan trading manual.
Aktifkan Push Notification (opsional) Buka Tools > Options > Notifications, centang Enable Push Notifications, lalu isi MetaQuotes ID dari aplikasi MT5 mobile. Diperlukan agar notifikasi pending order tereksekusi masuk ke HP. Detail di bagian 22.

C. Pasang EA ke Chart

Buka chart symbol target Buka chart instrumen yang ingin dikelola, misalnya XAUUSD. Pastikan timeframe sesuai strategi (EA bekerja di timeframe apa saja karena berbasis panel, bukan sinyal indikator).
Drag EA ke chart Dari panel Navigator, tarik EntryAjaib ke area chart. Jendela pengaturan EA akan muncul.
Atur Input Parameter awal Set nilai awal seperti InpMagicNumber, InpEntryLot, InpLayerCount, InpMultiStep, InpSLPoints, InpRewardRatio, dan parameter lain. Lihat detail di bagian "Input Parameter".
Klik OK EA akan dipasang ke chart. Jika InpShowPanel = true, panel statistik posisi muncul di kiri atas, dan tombol eksekusi muncul di kiri bawah. Watermark EntryAjaib v30.77 tampil di chart.
Verifikasi EA aktif Pastikan ikon EA di pojok kanan atas chart menampilkan wajah tersenyum (smiley). Jika wajah tertawa, berarti Algo Trading nonaktif. Jika wajah sedih, ada error inisialisasi — cek tab Experts dan Journal.

1. Gambaran Umum

EntryAjaib EA adalah alat bantu trading berbasis panel. Fungsi utamanya adalah mempercepat eksekusi dan membantu trader mengelola posisi yang sudah terbuka. EA ini bekerja pada symbol chart tempat ia dipasang, misalnya XAUUSD, EURUSD, GBPUSD, atau symbol lain yang didukung broker.

EA menggunakan library standar MetaTrader 5 Trade\Trade.mqh melalui objek CTrade. Saat inisialisasi, EA mengatur Magic Number, filling mode, parameter lot dari symbol broker, parameter kontrol dari input, mendeteksi akun cent, membuat UI, membuat watermark, dan memperbarui chart.

Fungsi Utama

  • Eksekusi Buy/Sell market satu klik.
  • Plan entry dengan garis entry, SL, TP, dan preview layer.
  • Eksekusi plan normal dan martingale.
  • Basket TP berdasarkan break even weighted average.
  • SL+ untuk stop loss kolektif dan manual profit lock.
  • BEP, partial profit, trailing stop, dan reset SL/TP.
  • Statistik posisi dan monitoring margin.

Batasan Penting

  • EA tidak membaca sinyal otomatis dari indikator.
  • EA tidak menjamin profit atau menghilangkan risiko market.
  • Martingale dan multi-layer dapat menaikkan exposure sangat cepat.
  • Semua perhitungan point mengikuti symbol dan spesifikasi broker.

6. Buy Now dan Sell Now

Tombol BUY NOW dan SELL NOW membuka satu posisi market. Keduanya menggunakan CurrentLot dari panel.

BUY NOW

  • Mengambil harga ASK sebagai harga open.
  • Jika SL/TP ON, SL dipasang di bawah harga open sejauh CurrentSL.
  • Jika SL/TP ON, TP dipasang di atas harga open sejauh CurrentSL x CurrentTPRatio.
  • Jika SL/TP OFF, order dibuka tanpa SL dan TP.

SELL NOW

  • Mengambil harga BID sebagai harga open.
  • Jika SL/TP ON, SL dipasang di atas harga open sejauh CurrentSL.
  • Jika SL/TP ON, TP dipasang di bawah harga open sejauh CurrentSL x CurrentTPRatio.
  • Jika SL/TP OFF, order dibuka tanpa SL dan TP.
Perhatian: Buy Now dan Sell Now adalah market order langsung. Tombol ini mengirim order ke broker begitu diklik, jadi pastikan lot, SL/TP toggle, dan chart symbol sudah benar.

7. SL/TP ON/OFF, Set SL, Set TP, Reset SL/TP

SL/TP ON dan SL/TP OFF

Toggle ini menentukan apakah order baru dari EA membawa SL dan TP otomatis. Sejak versi 30.75, status awalnya diambil dari input parameter InpSLTPEnabled (default true), sehingga tombol tampil sebagai SL/TP ON saat EA dipasang.

Status Efek pada order baru Kapan digunakan
SL/TP ON EA menghitung dan memasang SL/TP saat order dibuat. Trading normal dengan proteksi langsung.
SL/TP OFF EA mengirim order tanpa SL dan TP. Jika trader ingin mengatur SL/TP secara basket atau manual setelah entry.

Set SL

Tombol Set SL memasang ulang Stop Loss pada semua posisi symbol aktif dengan Magic Number EA. Untuk Buy, SL dihitung dari harga open dikurangi CurrentSL. Untuk Sell, SL dihitung dari harga open ditambah CurrentSL.

Set TP

Tombol Set TP memasang ulang Take Profit pada semua posisi symbol aktif dengan Magic Number EA. Jarak TP dihitung dari CurrentSL x CurrentTPRatio.

Reset SL/TP

Tombol Reset SL/TP mengubah SL dan TP posisi menjadi nol. Artinya posisi tidak lagi memiliki stop loss dan take profit.

Risiko: reset SL/TP dapat menghilangkan proteksi posisi. Gunakan hanya jika memang ingin mengganti metode exit, misalnya dengan Basket TP atau SL+.

8. Close dan Delete Pending

Tombol close digunakan untuk menutup posisi pada symbol aktif. Jika InpCloseOwnOnly aktif, EA hanya menutup posisi dengan Magic Number yang sama.

Tombol Fungsi Filter Catatan
Close All Buy Menutup semua posisi Buy. Symbol aktif dan filter Magic Number jika aktif. Memiliki retry sampai 10 kali.
Close All Sell Menutup semua posisi Sell. Symbol aktif dan filter Magic Number jika aktif. Memiliki retry sampai 10 kali.
CLOSE ALL Menutup semua posisi Buy dan Sell. Symbol aktif dan filter Magic Number jika aktif. Digunakan untuk keluar cepat.
DelPend Menghapus pending order. Symbol aktif dan Magic Number EA. Tidak menutup posisi market.
Catatan: fitur close profit/loss tidak tersedia sebagai tombol aktif pada UI versi 30.77. Tombol close yang aktif adalah Close Buy, Close Sell, dan Close All.

9. Plan Buy dan Plan Sell

Plan adalah fitur untuk merencanakan entry sebelum order benar-benar dikirim ke broker. Dengan plan, trader bisa melihat level entry, SL, TP, estimasi profit/loss, rasio risk reward, dan posisi layer.

Objek yang Dibuat Saat Plan Aktif

  • Plan_Line_Entry: garis entry yang bisa digeser.
  • Plan_Line_SL: garis Stop Loss.
  • Plan_Line_TP: garis Take Profit.
  • Plan_Shadow_*: garis dotted untuk preview layer tambahan.
  • Panel Plan Info di kanan bawah.
  • Tombol EX Normal dan EX Martingle.

Plan Buy

Saat PLAN BUY diklik, EA membuat entry di tengah area harga chart yang terlihat. SL berada di bawah entry, TP berada di atas entry, dan shadow layer berikutnya berada di bawah entry dengan jarak GRID.

Plan Sell

Saat PLAN SELL diklik, EA membuat entry di tengah area harga chart yang terlihat. SL berada di atas entry, TP berada di bawah entry, dan shadow layer berikutnya berada di atas entry dengan jarak GRID.

Cara Menggunakan Plan

Klik PLAN BUY atau PLAN SELL Pilih arah rencana berdasarkan analisis trading.
Geser garis entry Drag garis entry ke level harga yang diinginkan. Garis SL, TP, dan seluruh shadow layer ikut bergerak real-time selama garis masih ditarik (perbaikan versi 30.77; sebelumnya baru menyusul setelah tombol mouse dilepas).
Atur LOT, GRID, SL, TP, dan LYR Perubahan parameter akan memperbarui garis, shadow line, dan panel Plan Info.
Baca panel Plan Info Periksa tipe, lot x layer, entry, SL, TP, estimasi risk, estimasi profit, R:R, dan jarak point.
Eksekusi atau batalkan Klik EX Normal atau EX Martingle untuk eksekusi. Klik tombol plan yang sama lagi untuk menghapus plan.

10. EX Normal dan EX Martingle

Tombol execute hanya muncul ketika plan aktif. Setelah execute selesai, EA menghapus garis plan dari chart.

EX Normal

EX Normal mengeksekusi plan multi-layer dengan lot tetap. Setiap layer menggunakan CurrentLot. 

Contoh:
LOT = 0.50
LYR = 5

Layer 1 = 0.50 lot
Layer 2 = 0.50 lot
Layer 3 = 0.50 lot
Layer 4 = 0.50 lot
Layer 5 = 0.50 lot
Total   = 2.50 lot

Cara kerja order pada EX Normal

  • Layer pertama memakai harga entry utama dari garis plan.
  • Layer berikutnya dihitung dengan jarak GRID.
  • Plan Buy menempatkan layer lebih rendah dari entry utama.
  • Plan Sell menempatkan layer lebih tinggi dari entry utama.
  • Jika harga layer valid sebagai pending order, EA memilih Buy Limit, Buy Stop, Sell Limit, atau Sell Stop.
  • Jika harga terlalu dekat dengan market, EA membuka market order.
  • Jika SL/TP OFF, SL dan TP dikirim sebagai nol.

EX Martingle

EX Martingle mengeksekusi plan multi-layer dengan lot bertambah linear. Layer ke-1 memakai lot dasar, layer ke-2 memakai lot dasar dikali 2, layer ke-3 dikali 3, dan seterusnya. 

Contoh:
LOT = 0.50
LYR = 5

Layer 1 = 0.50 lot
Layer 2 = 1.00 lot
Layer 3 = 1.50 lot
Layer 4 = 2.00 lot
Layer 5 = 2.50 lot
Total   = 7.50 lot

Formula:
Total Lot = Lot Dasar x (Layer x (Layer + 1) / 2)
Risiko martingale: total lot meningkat cepat. Sebelum klik EX Martingle, periksa total lot, free margin, safe lot, margin level, garis MC, dan garis Liquidation Stop.

11. Basket TP

Basket TP digunakan untuk memasang Take Profit kolektif pada banyak posisi sejenis. Fitur ini menghitung break even berdasarkan weighted average dari harga open dan lot.

Formula BEP Basket

BEP = jumlah(lot x harga open) / jumlah(lot)

Karena memakai bobot lot, posisi dengan lot lebih besar lebih berpengaruh terhadap harga BEP.

Basket Buy

Tombol BASKET BUY mencari semua posisi Buy pada symbol aktif sesuai filter Magic Number. Jika ada posisi Buy, EA membuat garis BEP dan garis TP yang bisa digeser.

Basket Sell

Tombol BASKET SELL mencari semua posisi Sell pada symbol aktif sesuai filter Magic Number. Jika ada posisi Sell, EA membuat garis BEP dan garis TP yang bisa digeser.

Panel Basket TP

Informasi Arti

BEP Harga break even basket.
TP Harga target take profit dari garis TP.
Total Lots Total lot semua posisi dalam basket.
Distance Jarak dari BEP ke TP dalam point.
Est. Profit Estimasi profit jika seluruh basket mencapai TP.

Cara Menggunakan Basket TP

Pastikan ada posisi aktif Minimal harus ada satu posisi Buy untuk Basket Buy, atau satu posisi Sell untuk Basket Sell.
Klik BASKET BUY atau BASKET SELL EA membuat garis BEP dan garis TP.
Geser garis TP Tempatkan garis pada level target. Panel akan menghitung ulang estimasi profit.

12. SL+ / Basket SL

SL+ adalah fitur Basket SL. Fitur ini membuat garis Stop Loss kolektif berdasarkan BEP posisi. Garis SL+ bisa digunakan untuk membatasi kerugian atau mengunci profit manual jika garis diletakkan melewati BEP.

Cara EA Memilih Tipe Awal

  • Jika hanya ada posisi Buy, SL+ dibuat untuk Buy.
  • Jika hanya ada posisi Sell, SL+ dibuat untuk Sell.
  • Jika ada Buy dan Sell, EA memilih sisi dengan jumlah posisi lebih banyak.

Objek yang Dibuat

  • Garis BEP Buy atau Sell.
  • Garis SL+ yang bisa digeser.
  • Panel info SL+.
  • Tombol Ex SL Buy.
  • Tombol Ex SL Sell.

Isi Panel SL+

Informasi Arti

SELL info Jumlah posisi Sell, total lot Sell, dan BEP Sell.
Selected Tipe basket yang sedang dihitung.
BEP Break even tipe terpilih.
SL Harga SL dari garis SL+.
Distance Jarak dari BEP ke SL dalam point.
Est. Loss/Profit Estimasi loss jika SL di sisi rugi, atau profit jika SL melewati BEP.

Cara Menggunakan SL+

Klik tombol SL+ EA membuat garis BEP dan garis SL+ jika ada posisi aktif.
Geser garis SL+ Tempatkan garis pada level stop loss atau level profit lock.
Baca estimasi panel Pastikan estimasi loss/profit sesuai rencana.

Penggunaan utama tetap melalui tombol SL+, garis yang dapat digeser, dan tombol execute pada panel SL+.

13. BEP

Tombol BEP memindahkan Stop Loss posisi ke area break even plus buffer kecil. Buffer diambil dari input InpBEPProfitPoints (default 1000 points) dan dapat diubah langsung dari panel BEP di chart tanpa membuka pengaturan EA.

Panel Kontrol BEP

EA membuat panel kontrol BEP dengan tombol minus, kotak input, dan tombol plus. Nilai buffer dapat diatur dalam range 0 - 50000 points dengan step 100 points. Perubahan nilai buffer langsung dipakai saat tombol BEP diklik.

Tipe Posisi Rumus SL Baru Syarat
Buy Open Price + Buffer Harga Bid harus cukup jauh di atas SL baru dan melewati batas broker.
Sell Open Price - Buffer Harga Ask harus cukup jauh di bawah SL baru dan melewati batas broker.

Cara Menggunakan BEP

Atur buffer BEP Gunakan tombol plus/minus pada panel BEP atau ketik angka langsung di kotak input untuk mengatur jarak buffer (dalam points).
Tunggu posisi bergerak profit BEP memerlukan jarak harga yang cukup agar broker menerima perubahan SL.
Klik tombol BEP EA memproses posisi Buy dan Sell pada symbol aktif sesuai filter.
Cek posisi yang berhasil dimodifikasi Posisi yang belum memenuhi jarak minimum akan dilewati.
Validasi broker: EA memperhitungkan SYMBOL_TRADE_STOPS_LEVEL dan SYMBOL_TRADE_FREEZE_LEVEL. Jika posisi terlalu dekat dengan harga market, SL tidak dipindahkan.

14. TP Partial

Tombol TP½ menjalankan partial close untuk posisi yang sedang profit. Pada versi 30.77, persentase volume yang ditutup dapat diatur dari panel TP Partial, dengan range 10% - 90% dan step 5%. Default adalah 50% (setengah volume).

Panel Kontrol TP Partial

EA membuat panel kontrol TP Partial dengan tombol minus, kotak input persen, dan tombol plus. Nilai persen dipakai saat tombol TP½ diklik. Volume partial dihitung sebagai Volume × Persen / 100, lalu dibulatkan ke bawah ke kelipatan SYMBOL_VOLUME_STEP.

Syarat Posisi Diproses

  • Symbol sama dengan chart aktif.
  • Magic Number sama dengan InpMagicNumber.
  • Total profit posisi setelah swap lebih besar dari nol.
  • Volume posisi lebih besar dari minimum lot broker.
  • Sisa volume setelah partial close masih memenuhi minimum lot broker.

Contoh

Volume posisi = 0.10 lot
Persen TP Partial = 50%
Minimum lot broker = 0.01

TP Partial menutup 0.05 lot
Sisa posisi menjadi 0.05 lot
Volume posisi = 0.30 lot
Persen TP Partial = 30%
Lot step broker = 0.01

Volume partial = 0.30 x 30 / 100 = 0.09 lot
Sisa posisi menjadi 0.21 lot
Catatan: jika volume terlalu kecil atau sisa lot setelah partial kurang dari minimum lot broker, EA akan melewati posisi tersebut agar tidak melanggar minimum volume broker.

15. Trailing Stop

Trailing Stop berjalan pada OnTick hanya jika tombol TRAIL ON aktif. EA memproses posisi pada symbol aktif dengan Magic Number EA.

Buy Trailing

  • Trailing aktif jika Bid >= Open Price + Trail Distance.
  • SL baru dihitung sebagai Bid - Trail Distance.
  • SL hanya digeser jika SL baru lebih tinggi dari SL lama.

Sell Trailing

  • Trailing aktif jika Ask <= Open Price - Trail Distance.
  • SL baru dihitung sebagai Ask + Trail Distance.
  • SL hanya digeser jika SL baru lebih rendah dari SL lama, atau jika posisi belum punya SL.

Cara Menggunakan Trailing

Atur nilai TRAIL Gunakan plus/minus atau ketik jarak trailing dalam point.
Klik TRAIL OFF menjadi TRAIL ON Warna tombol berubah dan trailing mulai diproses setiap tick.
Monitor SL SL akan bergerak hanya saat posisi sudah profit minimal sejauh trail distance.

17. MC Line dan Liquidation Stop

EA membuat dua garis risiko saat ada posisi aktif milik EA pada symbol chart: garis Margin Call/Stop Out dan garis Liquidation Stop atau Zero Balance.

Margin Call / Stop Out Line

Garis MC memperkirakan level harga ketika equity mendekati batas stop out broker. EA membaca equity, margin terpakai, stop out level broker, tick value, tick size, total lot, dan arah net posisi.

  • Jika net Buy lebih besar, garis MC diperkirakan berada di bawah harga rata-rata Buy.
  • Jika net Sell lebih besar, garis MC diperkirakan berada di atas harga rata-rata Sell.
  • Jika posisi hedged seimbang, EA memakai pendekatan konservatif berdasarkan sisi Buy.

Warna Garis MC

Kondisi Warna Makna
Equity left < 10% Merah Sangat dekat dengan bahaya margin.
Equity left < 25% Orange red Warning kuat.
Equity left < 50% Orange Perlu waspada.
Lebih dari 50% Gold Masih relatif jauh, tetapi tetap perlu dipantau.

Liquidation Stop / Zero Balance Line

Garis ini memperkirakan level harga ketika equity menjadi nol. Perhitungannya memakai equity saat ini, tick value, tick size, total lot, dan arah net posisi dari harga market saat ini.

Interpretasi: garis Liquidation Stop bukan target yang boleh ditunggu. Jika garis ini terlalu dekat dengan harga, exposure posisi sudah terlalu besar dan risiko akun sangat tinggi.

18. Deteksi Akun Cent

EntryAjaib mencoba mendeteksi akun cent saat OnInit(). Jika akun terdeteksi sebagai cent, CentDivisor diatur menjadi 100.0 agar tampilan profit lebih wajar pada panel.

Metode Deteksi

  • Nama symbol mengandung cent, .c, _c, atau berakhiran c.
  • Currency akun adalah USC, EUC, GBC, CHC, AUC, NZC, CAC, JPY100, atau mengandung CENT.
  • Path symbol mengandung kata cent.
  • Contract size symbol bernilai 1000.0.

20. Workflow Penggunaan

Workflow 1: Entry Cepat dengan Proteksi SL/TP

Pastikan SL/TP ON Order baru akan membawa SL dan TP otomatis.
Atur LOT, SL, dan TP 1 Pastikan risiko sesuai akun.
Klik BUY NOW atau SELL NOW EA membuka satu posisi market.
Aktifkan BEP atau TRAIL jika perlu Gunakan setelah posisi bergerak profit.

Workflow 2: Plan Multi-Layer Normal

Klik PLAN BUY atau PLAN SELL Buat rencana entry di chart.
Geser entry Tempatkan di level analisis.
Atur GRID dan LYR Pastikan jarak layer dan total exposure masuk akal.
Baca Plan Info Cek risk, profit, dan R:R.
Klik EX Normal EA membuat order multi-layer dengan lot tetap.

Workflow 3: Plan Martingale

Gunakan lot dasar kecil Total lot martingale bertambah cepat.
Buat Plan Pilih Plan Buy atau Plan Sell.
Hitung total lot Pakai formula Lot x Layer x (Layer + 1) / 2.
Cek margin Lihat Safe Lot, Margin Level, MC line, dan Liquidation Stop.
Klik EX Martingle jika sudah siap Gunakan hanya setelah semua risiko dihitung.

Workflow 4: Mengatur Target Basket

Pastikan posisi sejenis tersedia Contoh beberapa posisi Buy.
Klik BASKET BUY atau BASKET SELL EA membuat garis BEP dan TP.
Geser TP basket Tempatkan target kolektif.
Klik execute TP EA memasang TP ke semua posisi basket.

Workflow 5: Mengunci Profit Manual dengan SL+

Klik SL+ EA membuat garis BEP dan SL.
Geser SL ke area profit Untuk Buy, garis di atas BEP berarti profit lock. Untuk Sell, garis di bawah BEP berarti profit lock.
Cek estimasi profit Panel akan menampilkan Est. Profit jika garis berada di sisi profit.
Klik Ex SL Buy atau Ex SL Sell EA memasang SL kolektif.

21. Catatan Risiko

Trading berisiko tinggi. EntryAjaib membantu eksekusi dan visualisasi risiko, tetapi tidak menghilangkan risiko market, spread melebar, slippage, stop out, koneksi terputus, atau kesalahan input lot.

Hal yang Harus Dicek Sebelum Entry

  • Chart symbol sudah benar.
  • Lot sudah sesuai modal.
  • SL/TP toggle sudah sesuai rencana.
  • Layer dan grid tidak terlalu agresif.
  • Total lot martingale sudah dihitung.
  • Margin level dan safe lot masih aman.
  • Garis MC dan Liquidation Stop tidak terlalu dekat.
  • Broker mengizinkan jarak SL/TP sesuai stop level dan freeze level.

Rekomendasi Penggunaan

  • Uji semua fitur di akun demo terlebih dahulu.
  • Gunakan lot kecil saat mencoba martingale.
  • Jangan menambah layer hanya untuk mengejar harga tanpa rencana exit.
  • Gunakan Basket TP dan SL+ untuk membuat exit kolektif yang jelas.
  • Gunakan BEP dan trailing setelah posisi bergerak profit, bukan sebagai pengganti rencana risiko awal.

22. Push Notification ke MT5 Mobile

Sejak versi 30.75, EA dapat mengirim notifikasi ke aplikasi MetaTrader 5 di HP setiap kali Pending Order milik EA tereksekusi menjadi posisi. Fitur ini dikendalikan input InpPushNotifPending.

Syarat Agar Notifikasi Terkirim

Isi MetaQuotes ID di terminal Buka Tools > Options > Notifications, centang Enable Push Notifications, lalu isi MetaQuotes ID yang tampil di menu Messages aplikasi MT5 mobile.
Klik Test Pastikan notifikasi percobaan masuk ke HP sebelum mengandalkan EA.
Set Magic Number Notifikasi hanya dikirim untuk deal dengan symbol chart aktif dan Magic Number yang sama dengan InpMagicNumber.

Isi Pesan

Format pesan: tipe pending order, symbol, volume, harga eksekusi, dan nomor ticket. Contoh:

Entry Ajaib: Pending BUY LIMIT XAUUSD 0.05 lot tereksekusi @ 2648.15 (#123456789)

Filter dan Batasan

Aspek Perilaku
Jenis event Hanya deal pembukaan posisi (DEAL_ENTRY_IN) yang berasal dari pending order. Market order dari BUY NOW / SELL NOW tidak memicu notifikasi, begitu juga close, SL hit, dan TP hit.
Tipe order Buy/Sell Limit, Buy/Sell Stop, dan Buy/Sell Stop Limit.
Filter Symbol chart aktif + Magic Number EA.
Rate limit Server MetaQuotes membatasi ~2 notifikasi per detik. EA memakai antrian dengan jeda ~700 ms per kirim, sehingga eksekusi banyak layer sekaligus tetap terkirim satu per satu, tidak ada yang hilang.
Jika gagal Pesan kena rate limit tetap disimpan dan dicoba lagi. Error lain (misalnya MetaQuotes ID belum diisi) membuat pesan dibuang agar antrian tidak macet, dan alasannya dicatat di tab Experts.
Tips: fitur ini paling berguna untuk plan multi-layer. Anda tidak perlu memantau chart untuk tahu layer ke berapa yang sudah kena.

23. Responsive UI (HiDPI / Retina)

Versi 30.76 membuat seluruh panel menyesuaikan diri dengan resolusi layar dan ukuran chart. Sebelumnya semua dimensi memakai angka pixel tetap, sehingga panel tampak sangat kecil di layar HiDPI/Retina (MacBook, monitor 4K) dan teks tombol bisa terpotong.

Cara Kerja

  • Seluruh dimensi dirancang untuk layar 96 DPI, lalu dikalikan faktor skala yang dihitung otomatis dari DPI layar.
  • Lebar tombol dihitung dari lebar teks yang benar-benar dirender terminal, bukan dari konstanta pixel. Inilah yang mencegah label seperti Set TP (1:2.0) terpotong.
  • Layout ditata ulang otomatis saat ukuran chart berubah. Scroll dan zoom tidak memicu relayout karena ukuran chart di-cache.
  • Auto Fit mengecilkan skala bertahap bila panel tidak muat di chart yang sempit.

Kalau Tampilan Masih Kurang Pas

Gejala Solusi
Panel terlalu kecil / terlalu besar Isi InpUIScale manual, misalnya 1.25 atau 1.5. Nilai 0 berarti otomatis.
Teks tombol terpotong Turunkan InpUIFontDelta ke -1 atau -2.
Teks terlalu kecil dibaca Naikkan InpUIFontDelta ke +1 atau lebih.
Panel menutupi chart di window kecil Pastikan InpUIAutoFit = true, atau kecilkan InpUIScale.
Catatan versi 30.77: penataan ulang layout ditunda sesaat (400 ms) selama garis Plan, Basket TP, atau SL+ sedang digeser. Memindahkan puluhan objek panel di tengah drag membuat MetaTrader melepas pegangan pada garis yang sedang ditarik.

  • Shadow line tidak lagi dihapus lalu dibuat ulang setiap update, melainkan dipindahkan. Ini menghilangkan gejala drag putus dan garis lompat.
